# Voci di Lumi

Non serve scaricare nulla a mano: in Lumi vai in **Impostazioni > Voce** e premi **Scarica Paola** o **Scarica Serena**.

Se vuoi il file comunque, una voce = un file ZIP:

| Voce | File | Licenza |
|---|---|---|
| Paola (media qualità, più leggera) | [Voce-Paola.zip](https://github.com/MATRIXNEO23/jarvis/releases/download/voci-lumi-v1/Voce-Paola.zip) | voce ufficiale Piper (rhasspy/piper-voices) |
| Serena (alta qualità) | [Voce-Serena.zip](https://github.com/MATRIXNEO23/jarvis/releases/download/voci-lumi-v1/Voce-Serena.zip) | CC BY 4.0, it_IT-serena-high by Marco Baccarani (Committa) |

`voci.json` è l'elenco tecnico che Lumi usa per scaricare e verificare le voci: non va aperto né modificato.
