JARVIS — ACCESSO FILE 0.1.0 / BUILD CANDIDATA PER WINDOWS 10 x64

Estrai questo ZIP in una cartella NUOVA. Avvia soltanto avvia_jarvis.bat.
La precedente cartella di Jarvis resta disponibile per tornare alla base.
Serve Python 3.11/3.12 x64 con Tk (incluso nell'installer ufficiale).
GPT esterno: stessa connessione/account, installa_gpt.bat se ancora assente.
Voce: installa_voce.bat se non già predisposta. Telegram: installa_telegram.bat
solo se usato. Le funzioni locali file non richiedono GPT o nuove librerie.

Questa build usa il profilo separato LOCALAPPDATA\Jarvis-AccessoFile-Trial.
Al primo avvio copia in modo consistente i dati del precedente profilo di
prova Telegram50, se presente; altrimenti usa il profilo Jarvis normale.
Non sovrascrive dati nella sorgente. Gli avvii seguenti conservano il profilo
AccessoFile esistente. Telegram automatico inizialmente spento, microfono
secondo il comportamento della base; controlla l'interruttore in impostazioni.
Non avviare due istanze Telegram contemporaneamente.

Impostazioni > Gestisci add-on: seleziona Accesso file > Configura.
Se l'add-on non compare, Installa scegliendo file_access\AccessoFile.jaddon.
Spunta disco/cartella, escludi eventuali sottocartelle, Salva, poi Attiva.
Nessuna cartella viene autorizzata soltanto perché l'add-on è installato.

Prova iniziale: seleziona una cartella con un TXT, poi di' o scrivi
"cerca file PARTEDELNOME" e "leggi file 1". Per una cartella:
"apri cartella 1". "Spiega file 1" richiede il GPT collegato e invia
un estratto del file; la semplice lettura resta locale sul tuo computer.
Dettagli, limiti e comandi: file_access\LEGGIMI.md.

La build non modifica/cancella i file trovati. Mostra testo supportato in
sola lettura e apre cartelle in Explorer. L'indice Windows puo' mancare:
in quel caso cerca direttamente nelle cartelle autorizzate con limiti.
Per tornare indietro chiudi questa build e usa la vecchia cartella;
non cancellare nessuno dei profili dati. Nessun add-on abilita UAC/ACL.
